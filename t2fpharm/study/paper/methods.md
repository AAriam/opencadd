Structures are mostly selected from the [Patel dataset](https://doi.org/10.1023/A:1021954728347),
  which contains a collection of five structurally diverse and well-described protein families,
  for which a large number of structural data is available
  and has been used to evaluate other tools in the context of pharmacophore modelling.
  Here, we only use four of the five families,
  discarding the zinc-containing protein, thermolysin,
  as this version of the T²F method is not suitable for the detection of metal coordinations.
  Instead of thermolysin, the adenosine A2A receptor is included in our set
  to represent the GPCR class of proteins.
  The dataset thus contains ligand-enzyme complexes for:

  - Cyclin-dependent kinase 2 (CDK2, 6 entries)
  - Dihydrofolate reductase (DHFR, 6 entries)
  - Thrombin (THROM, 7 entries)
  - HIV-1 reverse transcriptase (HIVRT, 10 entries)
  - Adenosine A2A receptor (A2AR, 3 entries)
